# 화살 군단 - Arrow Legion

브라우저에서 바로 실행되는 한 파일짜리 캔버스 게임입니다. 외부 라이브러리는 쓰지 않습니다.

- 게이트(+N, ×2, −N)를 골라 궁수 병력을 늘리고, 적 무리와 통을 거쳐 보스를 쓰러뜨립니다.
- 조작: 드래그 또는 ←/→ (A/D) 키. 탭이나 Space/Enter로 시작합니다.
