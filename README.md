# 화살 군단 - Arrow Legion

브라우저에서 바로 실행되는 한 파일짜리 캔버스 게임입니다. 외부 라이브러리나 파일 없이 동작합니다(효과음도 코드로 합성).

- 게이트(+N, ×2, ÷2, −N)를 골라 궁수 병력을 불립니다. 게이트를 쏘면 숫자가 올라갑니다.
- 몰려오는 적 무리, 거인, 회전 톱날을 뚫고 지나갑니다.
- 포로 감옥을 부수면 아군이 합류하고, 강화 구슬(불화살·속사)을 먹으면 그 판 동안 강해집니다.
- 보스는 빨간 구역에 내려찍기를 예고합니다. 피하면서 쏘세요.
- 코인으로 병력·공격력·연사를 영구 강화합니다(브라우저에 저장).
- 조작: 드래그 또는 ←/→ (A/D). Space/Enter로 시작, 1·2·3으로 강화, M으로 소리 끄기.
